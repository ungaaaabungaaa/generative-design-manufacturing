# Security and operational limits

This local study writes files only into a new output directory and refuses existing destinations. Configurations are bounded regular JSON files. Dimensions, numeric inputs, search seeds, and candidate budgets are validated before generation. The CLI is a local research tool, not a service for arbitrary untrusted filesystem requests.

The viewer has no account, analytics, external fonts, uploaded data, network model, or remote code execution. Its local server binds to loopback, validates Host, and serves public app/report/export files only. Security headers restrict browser resources to the same origin. Host only `dist/` on a static service for public deployment; the development server is not a production server.

Exports are geometry/data, with no machine-motion commands. Their successful creation does not certify physical or manufacturing safety. Validate any later hardware use independently.

Use private vulnerability reporting when available. Otherwise open a minimal issue explaining impact without credentials, private files, or an active exploit. Do not publish secrets in reports.
